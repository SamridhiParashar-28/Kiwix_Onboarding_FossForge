Works completely off-grid. Static bundled catalogues and local Web Storage APIs eliminate all telemetry and cloud server dependencies.

Adaptive Storage Budget

Set 1GB, 5GB, or 20GB disk targets or auto-detect device storage. Overload protection guarantees your selected content never exceeds disk capacity.

Resilient Resumable Engine

Chunked retrieval modeling with simulated network drop test, exponential backoff, and transparent ETA based on your connection speed.
